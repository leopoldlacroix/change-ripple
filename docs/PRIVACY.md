# Privacy: Change Ripple demo
(Draft for a demo, not legal advice. The publisher must confirm it matches the build and settings.)
- **Collected:** sample brand data; draft text and rejection reasons sent to the tools; status, history and timestamps. The app asks for no names or accounts and has no analytics.
- **Use:** only to run the demo.
- **Storage and processors:** Cloudflare hosts the server and storage and processes technical request data under its own terms. This Worker does not log request bodies, draft text, tokens or workspace IDs.
- **Claude:** what you type in Claude and what tools return is also handled by Claude under your agreement with Anthropic.
- **Sharing:** no sale or sharing by the publisher beyond the hosting provider.
- **Retention:** sandboxes are deleted 7 days after creation. Cloudflare may retain infrastructure backups under its own terms; this app does not keep a second copy.
- **Access:** anyone with a workspace ID can read and change that sandbox. Do not enter personal, confidential or real brand data.
- **Contact:** open an issue on this repository.
